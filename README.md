SISTEMA PARA RENTA DE MOBILIARIO PARA EVENTOS/FIESTAS

Descripción
Este proyecto consiste en el diseño de un sistema de base de datos para administrar el proceso de renta de mobiliario y productos para eventos. El sistema permite registrar clientes, empleados, productos disponibles, rentas realizadas, detalles de cada renta y los pagos correspondientes.

Motivacion
La motivación del proyecto es resolver la necesidad de llevar un control ordenado y confiable de las rentas, productos y pagos dentro de un negocio de mobiliario para eventos. Muchos de estos negocios manejan la información de forma manual o en hojas sueltas, lo que puede provocar errores, pérdidas de datos y mala administración del inventario.
